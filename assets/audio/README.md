# Audio library

CC0 1.0 (public domain) sound effects and music, from the library in
[kmilo93sd/agent-video-editor](https://github.com/kmilo93sd/agent-video-editor) (sources: Kenney, OpenGameArt, generated).
Free for commercial use, no attribution required. Details: `SOURCE-LICENSES.md`.

The render workflow copies this folder to `public/kodvid-audio` in each Remotion project. The kit uses it automatically
(`sfx: true`, `music: "<name>"` in `src/video.ts`).

Music note: CC0 does not stop someone from registering a track in Content ID. For Instagram and TikTok,
adding music in the app from its licensed library is safer and helps reach.
